# The Victim's client times its Whispers

Elsewhere the Master decides and every client applies, and the Mimic follows that rule through a command from the Master. The Whispers do not: once the Master's Attachment makes the Victim Haunted, the Victim's client alone decides when each Whisper plays and from which side. A Whisper is heard by the Victim alone and changes no game state, so a command from the Master would only add a wire contract to keep, for a timing nobody else can observe.

## Consequences

A Whisper never reaches the network: there is no RPC or room property to keep stable for it, and two mod versions can time Whispers differently without breaking each other.
